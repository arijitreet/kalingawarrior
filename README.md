# Kalinga Warriors

React + Vite + Tailwind + Framer Motion team showcase and stats dashboard.

## Setup

1. `npm install`
2. `npm run dev`

## Build

- `npm run build`
- `npm run preview`

## Features

- Hero section with fade-in
- About + stats cards with scroll animation
- Achievements cards with gold/silver styling
- Parallax team banner
- Interactive players grid with hover stats
- Tournament table with winner highlighting
- Fixed WhatsApp join button with pulse effect
- Mobile/tablet/desktop responsive layout
- JSON data layer in `src/data`
